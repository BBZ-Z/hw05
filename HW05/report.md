# 人工智能导论 作业05：极简CNN与LeNet-5手写数字识别实验报告
一、实验目的
1. 掌握卷积神经网络（CNN）的基础组成结构，包括卷积层、池化层、全连接层的作用。

2. 自主搭建极简卷积神经网络，完成MNIST手写数字数据集分类任务。

3. 复现经典 LeNet-5 网络结构，理解早期经典卷积网络的设计思想。

4. 对比极简CNN与LeNet-5在参数量、训练速度、识别准确率上的差异，分析网络结构对模型性能的影响。

5. 熟悉PyTorch模型搭建、数据集加载、模型训练、测试评估的完整流程。

二、实验环境
操作系统：Windows

编程语言：Python 3.9+

框架版本：torch 2.1.0、torchvision 0.16.0

运行设备：CPU / CUDA GPU

三、实验原理与网络结构
3.1 卷积神经网络基础原理
卷积神经网络（CNN）是专门用于图像任务的深度学习模型。主要由卷积层、池化层、激活函数、全连接层组成。卷积层负责提取图像边缘、纹理、轮廓等局部特征；池化层用于下采样，降低特征图尺寸，减少参数量，同时提升模型泛化能力；激活函数引入非线性能力，使模型可以拟合复杂图像特征；全连接层负责将二维特征展平，完成最终分类。

3.2 极简CNN网络结构
本次搭建的极简CNN包含两层卷积池化结构与两层全连接层。输入为28×28单通道手写数字图片，通过卷积提取特征、池化降维，最后通过全连接层输出10分类结果。

3.3 LeNet-5网络结构
LeNet-5 是1998年提出的首个经典卷积神经网络，专为手写数字识别设计，结构精简高效，是现代CNN网络的基础原型。本次适配MNIST数据集对网络padding进行微调，保证输入输出尺寸匹配。

LeNet-5详细结构参数如下表所示：

层类型	输入尺寸	输出尺寸	参数量（约）	说明
卷积层Conv1	1×28×28	6×28×28	156	6个5×5卷积核，padding=2
池化层Pool1	6×28×28	6×14×14	0	2×2平均池化
卷积层Conv2	6×14×14	16×10×10	2416	16个5×5卷积核
池化层Pool2	16×10×10	16×5×5	0	2×2平均池化
卷积层Conv3	16×5×5	120×1×1	48120	120个5×5卷积核
全连接层FC1	120	84	10164	全连接+ReLU
全连接层FC2	84	10	850	输出分类结果
四、实验流程
1. 数据预处理：加载MNIST手写数字数据集，对图像进行归一化处理，统一数据分布，加速模型收敛。

2. 模型搭建：分别搭建极简CNN网络与经典LeNet-5网络。

3. 模型训练：设置统一超参数（batch_size=64，学习率0.001，迭代5轮），使用Adam优化器、交叉熵损失函数训练模型。

4. 模型测试：关闭梯度更新，在测试集上计算模型分类准确率、训练耗时。

5. 对比分析：统计两个模型的性能指标，分析网络结构优劣。

五、实验结果与对比分析
5.1 模型实验结果对比
模型	测试准确率	参数量（约）	训练耗时（CPU）
极简CNN	~98.5%	218k	~60秒
LeNet-5	~98.8%	61.7k	~45秒
5.2 结果分析
1. 参数量对比：LeNet-5 参数量远低于极简CNN，仅为极简CNN的约四分之一，网络结构更加轻量化，参数利用率更高。

2. 准确率对比：在MNIST简单手写数字数据集上，LeNet-5 识别精度略高于自建极简CNN，证明经典卷积网络的分层卷积、逐级降维的设计更加科学，能够更精准提取图像特征。

3. 训练速度对比：得益于更少的参数量，LeNet-5训练计算量更小，收敛速度更快，训练耗时短于极简CNN。

4. 整体来看：并非网络层数越多、参数越大效果越好，合理的网络结构设计可以在更低算力消耗下达到更高的识别精度。

六、实验问题与解决
1. 数据集下载超时：torchvision官方源不稳定，通过切换网络、重试下载解决。

2. 维度不匹配报错：搭建网络时核对卷积核、步长、padding参数，保证特征图尺寸与全连接层输入对应。

3. CUDA显存不足：降低batch_size大小，兼容CPU与GPU双模式运行。

七、实验总结
本次实验成功搭建并训练了极简CNN网络与经典LeNet-5卷积神经网络，完成MNIST手写数字分类任务。通过实验掌握了卷积层、池化层、全连接层的作用，熟悉了深度学习模型完整训练流程。

同时通过两组模型对比，深刻理解了网络结构轻量化、参数设计对模型性能、训练效率的重要影响。经典LeNet-5作为卷积神经网络的开山模型，结构精简高效，非常适配简单图像分类任务。本次实验完成了课程学习目标，加深了对卷积神经网络原理的理解。
